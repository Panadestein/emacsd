My personal Emacs configuration, written as a literate Org document. It covers everyday editing,
software development, remote work with TRAMP, terminals, notes, and a broad collection of
programming-language modes.

The annotated configuration is easier to explore on the
[[https://panadestein.github.io/emacsd/][published website]], where the table of contents and source code appear side by side.

* Repository layout

- =content/index.org= is the documented source of the configuration.
- =init.el= and =early-init.el= are the corresponding Emacs startup files.
- =build-site.el= exports the website with Org and the vendored =htmlize= package.
- =content/site.css= and =content/site.js= provide the self-contained website interface.

* Building the website

With Emacs installed, run:

#+BEGIN_SRC shell
./publi.sh
#+END_SRC

The static site is written to =public/=. The build does not download themes or Emacs packages.

This is an evolving personal setup rather than a general-purpose Emacs distribution. Read through
the configuration and adapt it to your system before using it wholesale.
